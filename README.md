# 🤖 Customer Churn Prediction Using Artificial Neural Network (ANN)

An AI-powered machine learning project that predicts whether a customer is likely to leave a service or continue using it. This project uses an **Artificial Neural Network (ANN)** built with TensorFlow and Keras to perform binary classification based on customer behavior.

## 📌 Project Overview

Customer churn prediction helps businesses identify customers who may stop using their services.

This project builds a neural network model using customer information such as:
- Tenure
- Monthly Charges
- Data Usage
- Support Tickets
